## План задач для exchange-rate-cli


Задача 1. Утилиты дат
- Реализовать `timeutil` для парсинга `--date` (YYYY-MM-DD), дефолт сегодня, и конвертации в формат CBR `DD/MM/YYYY`.
- Тесты: валидные/невалидные даты, временные зоны, дефолт.

Задача 2. Модели и парсер CBR
- Определить модели XML (`ValCurs`, `Valute`) и функцию пересчёта `Value/Nominal` в float64 RUB.
- Добавить `testdata/cbr_daily_sample.xml` из README и покрыть парсер unit-тестами (корректный парсинг, запятая как разделитель, отсутствие валюты).

Задача 3. HTTP-клиент к CBR
- Клиент с базовым URL `https://www.cbr.ru/scripts/XML_daily.asp`, таймаутом и контекстом.
- Обработка статуса/сетевых ошибок, возврат осмысленных ошибок для CLI.
- Тесты через `httptest.Server`: 200 c валидным XML, 404/500, таймаут, битый XML.

Задача 4. Сервис получения курса
- Сервисный слой над клиентом и парсером: получение конкретного кода (CharCode), учёт `Nominal`, форматирование курса до 4 знаков.
- Подключить к команде `rate`, валидация кода, человекочитаемые ошибки.
- Тесты на сервис и команду (табличные, use fake client/parsers).

Задача 5. Сервис списка курсов
- Функция возврата всех валют за дату, сортировка по `CharCode` и отображение номинала.
- Подключить к команде `list` с флагом `--json` согласно README.
- Тесты: успешный список, json вывод, отсутствие данных, ошибки клиента.

Задача 6. Форматирование вывода
- Модуль `format`: табличный вывод (tabwriter) и JSON структура как в README, единый `ValueRUB` после деления на `Nominal`.
- Золотые тестовые файлы/снапшоты для rate/list (table и json), проверка округления.

Задача 7. Ошибки и коды возврата
- Единый слой ошибок: различать пользовательские ошибки (невалидные флаги/коды) и системные (сетевые/парсинг), привести сообщения к читаемому виду.
- Убедиться, что `main` возвращает код 1 на ошибке; покрыть тестами команд с ошибками.
